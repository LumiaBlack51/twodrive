# 百度网盘本机预览

百度适配器使用网盘开放平台官方 API，注册在正常的“添加连接”界面。支持官方网页授权、刷新授权、账号容量、逐目录浏览、流式下载、手动编辑及 Windows 挂载。2026-10-29 起连接后默认可编辑，不再需要本机写入密码；写入与回收站边界见 [默认可编辑说明](default-editable-2026-10-29.md)。

## 登录与挂载

1. 在开放平台创建并上线自己的应用，获取 AppKey / API Key 和 SecretKey。只在本机客户端填写，不提交到 GitHub 或发到聊天。
2. “连接 → 添加连接 → 百度网盘”，填写应用凭据，点击“百度官方网页登录 / 更新授权”。客户端显示设备授权码并打开 `https://openapi.baidu.com/device`，在百度网页亲自登录和授权。
3. 回到客户端点击“我已授权，继续”。未完成、拒绝或过期会明确提示；取消保留之前有效的登录。设备码流程不依赖 OAuth 回调地址配置。
4. 保存并连接后，每条连接可查看容量、浏览和下载文件；安装 WinFsp 的 Windows 可使用卡片上的“挂载”及“打开挂载”，与 OneDrive、iCloud 同时挂载。
5. 高级设置中的挂载目录应是尚不存在的独立子目录，例如 `D:\TwoDrive\Baidu`。可以创建父目录，不要预建最终挂载目录。退出前完成文件管理器中的复制。

授权根目录默认 `/`；应用只有应用目录权限时可填写其实际路径。可见文件及下载受百度应用资格、授权范围和服务限制约束。API 不返回容量时显示无法获取，不扫描整盘推算。

## 数据与能力边界

- AppKey、SecretKey、访问和刷新令牌存放在独立私有账号目录。Windows 用当前用户 DPAPI 加密，Unix 使用私有文件权限；普通配置、公开状态和错误不返回凭据。一次性授权输入不写入 profiles.json。
- 网页显示码与内部设备令牌分开。回答和取消绑定最新 attempt；旧界面不能取消新登录。后台恢复不自行打开登录窗口。
- GUI 与挂载 worker 可共享登录；刷新在文件锁内串行更新，轮转后先持久化再核验账号。核验暂时失败可重试，实际账号改变则拒绝旧连接。worker 仍受 kind、revision、binding 限制。
- 路径与远端 fs_id 分开。下载前后检查账号、fs_id、路径、类型、大小和服务端版本摘要，核对流长度及响应提供的 Content-MD5。内容响应摘要支持严格的 32 位十六进制和标准 Base64，均须还原为 16 字节并与实际内容匹配；无效/不匹配仍拒绝。元数据 MD5 当作不透明版本标识，不假定总是明文摘要。失败不发布成功文件。2026-10-29 的格式兼容修正及验收边界见 [TD-20261029-32](incidents.md#td-20261029-32百度挂载可枚举文件但复制返回-io-错误)。
- 下载和重定向只允许 HTTPS 百度受信任域名。错误不回显 URL、上游正文或令牌；API 有超时、重试、分页及响应大小预算。
- 只读：未开放上传、改名、删除、新建目录、双向同步或备份。首次挂载读取会完整下载文件到临时缓存。API 支持普通写入不等于具备项目要求的原子条件写入。
- 容量字段 `free` 是免费套餐额度，剩余空间由 `total - used` 计算。
